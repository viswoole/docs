# 快速开始

本章面向第一次接触 Viswoole 的开发者，带你完成从环境准备、项目创建到服务启动的完整流程，并解释项目各目录的职责与请求的运行方式，让你对框架建立整体认知。

## 前置条件

开始前请确认你具备：

- 熟悉 PHP 基础语法与 Composer 的基本用法
- 能够进行命令行（终端）操作
- 对 Swoole 协程（Coroutine）有初步概念即可，不要求深入

环境本身的要求（PHP 版本、扩展清单）在 [安装说明](1.installation.md) 中有完整核对清单。

### [安装说明](1.installation.md)

教程向导，全程照做即可跑通第一个应用：

1. 核对环境：PHP >= 8.4、Swoole 扩展 >= 5.1
2. `composer create-project viswoole/viswoole` 创建项目
3. 执行初始化命令同步框架资源
4. `php viswoole server:start` 启动，`curl` 验证 9501 端口响应

### [项目结构介绍](2.project-structure.md)

解释向导，回答「框架在什么时候做了什么」：

- `app/`、`config/`、`runtime/` 等目录各司其职
- 进程启动阶段与服务提供者注册只发生一次，请求处理阶段每个请求都发生
- 容器单例按请求（根协程）隔离，以及常驻内存模型的写代码红线

## 学习路径建议

```text
1. 核对环境 → 2. 创建项目 → 3. 启动服务 → 4. 理解目录与生命周期 → 5. 编写业务
```

- 如果你**刚接触常驻内存框架**，请务必读完「项目结构介绍」中的请求生命周期一节——Swoole 常驻内存与传统 PHP-FPM「一次请求一次加载」的模型差异，是后续避坑的关键。
- 如果你**只关心跑通 Demo**，直接阅读 [安装说明](1.installation.md) 即可，遇到问题再回来看结构说明。
