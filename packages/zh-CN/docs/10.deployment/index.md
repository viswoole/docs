## 快速检查清单

### 部署前必检项

- [ ] `.env` 文件已正确配置（`APP_DEBUG=false`）
- [ ] Swoole 扩展已安装且版本符合要求
- [ ] 目录权限已正确设置
- [ ] 日志目录可写
- [ ] 缓存目录可写
- [ ] 数据库连接正常
- [ ] Redis 连接正常（如使用）
- [ ] 端口未被占用
- [ ] 防火墙规则已配置
